## 五、技术及 SEO 注意事项

1. 页面使用 HTML + CSS 实现，不依赖外部框架。
2. 使用响应式布局，适配手机和电脑。
3. 页面只保留一个 H1。
4. FAQ 使用正常可见的 HTML 内容。
5. 设置 Canonical 指向新域名首页。
6. 不使用隐藏关键词、关键词堆砌等 SEO 手法。
7. 如果仍拥有原域名控制权，建议配置 301 跳转至新域名。
8. 如果无法控制原域名，则确保新域名可以正常访问，并提交 Sitemap。
9. 建议将通知页面直接设置为新域名首页 `/`。
